# Licenças e proveniência

Nenhum sprite, fonte, som ou imagem externo foi introduzido. O manifesto de assets deve inventariar cada arquivo distribuído com licença e proveniência; ausência de informação deve bloquear o gate. Não copiar assets ou código do Maestri.

Dependências npm possuem inventário no lockfile; `npm audit` verifica vulnerabilidades, não substitui auditoria legal. Licenças transitivas Rust e SBOM ainda dependem de ferramentas e lockfile completos. A licença de distribuição do código CIRANDA deve ser definida pelo proprietário antes de distribuir; este documento não concede direitos nem escolhe uma licença em seu nome.

O gate local não é controle contra alguém modificar deliberadamente o código/configuração de build. Empacotamento oficial dependerá dos Selos e do fluxo GC-11.
